Eng: 
This mod adds a powerful late-game device that allows colonists to fully reveal the entire map. Each scan requires 100 Uranium. The scanning speed depends on the pawn's Intellectual skill.

[b]Balance Changes:[/b]
• Requires late-game research to unlock
• Requires at least level 15 Construction skill to build
• Requires at least level 6 Intellectual skill to operate

[b]Settings:[/b]
• Adjustable map revelation speed
• Option to operate without Uranium consumption

Note: This mod was created with AI assistance.

Rus:

[b]Настройки:[/b]

• Возможность работы без использования урана


Внимание: Мод создан с использованием ИИ.
